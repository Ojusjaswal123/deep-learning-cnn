# Functional Models

This folder contains examples built using TensorFlow/Keras Functional API.

## Projects

### 1. First Functional Model

**File:** `first-functional-model.ipynb`

This notebook demonstrates:
- Creating input layers using `Input()`
- Building neural networks with the Functional API
- Connecting layers explicitly
- Creating a model using `Model(inputs, outputs)`
- Viewing the model summary

### Why Functional API?

The Functional API is more flexible than Sequential models and allows:
- Multiple inputs
- Multiple outputs
- Non-linear architectures
- Shared layers
- Complex deep learning models
